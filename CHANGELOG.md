# Change Log

All notable changes to PreVisX are documented in this file.

## [Unreleased]

- Added deterministic detection for Node.js, Python, Java, and C/C++ project types.
- Added project-aware readiness checks for runtimes, dependencies, environment files, configuration, builds, and declared ports.
- Added the Diagnosis Engine with severity, evidence, blocking status, and recommendations.
- Added Safe Fix plans for Node.js dependencies, Python virtual environments, and environment templates.
- Added explicit approval before any Safe Fix command or file operation.
- Added PreVisX branding, PVX activity bar icon, and the readiness sidebar.
- Added webview HTML escaping and nonce-based Content Security Policy hardening.
- Added fixed-command validation and active-workspace boundary checks for Safe Fixes.

PreVisX has not been published to the Marketplace and does not include AI, cloud services, analytics, or automatic runtime installation.
